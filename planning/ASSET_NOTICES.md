# Asset notes and provenance

- Story, dialogue, episode configuration, vector identity, UI concept, reference code and procedural sound-effect recipes were prepared for this project in this session. Choose the application/source and original-asset licence before public release; this pack does not replace that decision.
- The cinematic cover is generated artwork. Its prompt is included in `brand/ARTWORK_PROMPT.txt`. No stock watermark, third-party character or real radio-station logo is intentionally included.
- DejaVu font files are bundled unchanged. Preserve `brand/fonts/FONT_LICENSE.txt` when redistributing them. The outlined wordmark was made from those fonts; the editable variant needs the actual font.
- WAV effects in `audio/sfx` are original procedural synthesis, not samples from a commercial library. They are effects only; no presenter/captive narration is delivered. The voice manifest is a preparation plan, not generated audio.
- Gemma and Kokoro model weights are not bundled. Review their model cards/terms when downloading and retain any required notices. An application's MIT licence would not automatically cover those weights.
- No public repository, live application, measured gameplay performance, completed browser integration or published submission is delivered by this planning pack.
