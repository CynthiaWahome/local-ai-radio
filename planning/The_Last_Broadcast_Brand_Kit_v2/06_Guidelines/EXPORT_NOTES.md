# Export notes

The full composition is preserved in every raster export using proportional scaling and near-black padding. Nothing is stretched or cropped. The square card deliberately uses a letterboxed composition to retain both the title and captive; it is not a bespoke square illustration.

Transparent PNG logos are raster exports, not outlined vectors. SVG logos keep editable text. Install DejaVu Serif Bold from 07_Fonts when editing the wordmark.

The generated artwork has baked-in typography; use the SVG logos for independent placement. Do not use the campaign poster behind live game controls.
