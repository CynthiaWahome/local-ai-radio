# Brand implementation

Use Behind the Glass everywhere. The window silhouette is the primary logo; retire the old microphone and radio-wave mark and all alternative concept art.

Use the wide cover as promotional key art, not as an interactive UI screenshot. Keep live UI text in HTML; never place buttons over baked-in poster lettering. For a gameplay background, use a separately commissioned text-free adaptation.

Maintain near-black, sickly glass green and aged ivory, with red reserved for ON AIR, deadlines and danger. The figure should be recognizable but its identity unresolved. Horror belongs in the imagery; sarcastic comedy belongs in dialogue. Avoid pumpkins, novelty horror fonts and flashing effects. Honour reduced motion.

Transparent logos have no background. Prefer the ivory mark on dark UI and ink on pale surfaces. Use the 512 px icon for installation and the ICO/SVG for browser tabs.

All exports are numbered by usage. DEV.to cover: 1000 × 420; retina: 2000 × 840. Test cropping on the actual publishing preview.
