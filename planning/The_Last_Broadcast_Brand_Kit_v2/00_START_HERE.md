# The Last Broadcast — Brand kit v2

Approved direction: BEHIND THE GLASS. Psychological Halloween horror: an abandoned station and a captive presence behind a window. Replaces the earlier microphone/signal brand.

## Numbered folders
1. Logos: transparent PNGs and editable SVGs; ivory for dark backgrounds, ink for light backgrounds.
2. Icons: window-and-silhouette mark, favicon ICO/SVG and app sizes.
3. DEV.to: upload the 1000 × 420 cover; 2000 × 840 is the double-resolution alternative. Keep the title and hand inside the central safe area.
4. Social and README: 1200 × 630 sharing card, 1600 × 900 README and 1080 × 1080 square card.
5. Artwork: generated master.
6. Guidelines: palette, CSS tokens, asset manifest and agent handoff.
7. Fonts: supplied local UI fonts and licence. SVG wordmarks use editable DejaVu Serif text; supplied raster PNGs preserve appearance without installed fonts.

Product tagline: Five questions. No acceptable answers.
Campaign line: DON’T LET HIM FINISH.

DEV.to cover ratio reference: https://dev.to/smitterhane/what-size-should-a-cover-image-of-a-post-be-2n9b

Artwork was created using built-in image generation. Editable vector marks are purpose-built SVGs. No third-party station imagery or logos. Font terms are included.
